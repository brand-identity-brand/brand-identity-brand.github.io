# Personal Site

This directory contains the Vite + React website deployed at
`brand-identity-brand.github.io`. Its entry point will mount the configured
personal OS from the workspace's `packages/os` package.

Site-owned concerns include HTML, public assets, metadata, analytics,
top-level error handling, and static-host deployment.

Run the site from the workspace root:

```bash
npm run dev
```

Create a production build with:

```bash
npm run build
```
